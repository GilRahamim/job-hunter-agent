| סקיל | מה הוא מלמד |

| `cv-profile` | קריאת קורות החיים והפקת פרופיל מובנה עם LLM, כולל fallback בלי LLM |
| `job-matching` | מסננים (כולל ערים בעברית ומשרות remote שפתוחות לישראל — 22 מקרי בדיקה שעוברים), ניקוד מקדים, פרומפט הדירוג וסולם הציונים, אוצר מיומנויות |
| `agent-pipeline` | גרף LangGraph, ה-CLI, תזמון יומי ב-Windows |
| `job-storage` | סכמת SQLite וחוק הזהב: הסוכן אף פעם לא דורס סטטוס/הערות שלך |
| `job-dashboard` | דשבורד Streamlit בעברית (RTL): טבלה עם עריכת סטטוס, פאנל פרטים, תובנות ופערי מיומנויות |
| `offline-testing` | בדיקות בלי רשת ובלי API: fixtures, LLM מזויף, ורשימת מה חייב להיבדק |
| `cv-tailoring` | הסוכן השני: קו"ח מותאמים לכל משרה מתוך "קו"ח מאסטר", עם לולאת בדיקה שמונעת המצאות, ופלט DOCX מתבנית Word |

## איך מתחילים

1. **פתחו את התיקייה ב-Claude Code**
   ```bash
   cd job-hunter-agent
   claude
   ```
2. **שימו את קורות החיים** בתיקייה `cv/`.
3. **צרו קובץ `.env`** מ-`.env.example` עם מפתח ה-API (או הגדירו `provider: none` ב-`config.yaml` להתחלה בלי עלות).
4. **בנו שלב אחרי שלב** — העתיקו את הפרומפט של כל שלב מ-`docs/IMPLEMENTATION_PLAN.md`. לדוגמה:
   > Read CLAUDE.md and docs/ARCHITECTURE.md, then do Phase 0 of docs/IMPLEMENTATION_PLAN.md.

   בסוף כל שלב בקשו לראות את פלט בדיקת הקבלה לפני שממשיכים.

## טיפים לעבודה עם Claude Code בפרויקט הזה

- **שלב אחד בכל פעם.** שלב 2 (מקורות) הוא הגדול — אפשר לפצל: קודם ATS, אחר כך JobSpy, אחר כך remote.
- **Plan mode** (`Shift+Tab` פעמיים) לפני שלבים גדולים: Claude מציג תוכנית לפני שהוא כותב קוד.
- **Commit אחרי כל שלב שעבר** — קל לחזור אחורה.
- **לבדוק שסקיל נטען**: אם Claude לא השתמש בסקיל, כתבו במפורש "Use the job-matching skill".
- **עדכון הידע**: כשמשהו משתנה (API שינה מבנה, החלטה חדשה) — בקשו מ-Claude לעדכן את הסקיל או את `ARCHITECTURE.md`, לא רק את הקוד.
- **אחרי הריצה הראשונה האמיתית**: עברו על 10 משרות מדורגות. אם הציונים לא הגיוניים, התיקון הוא בסולם שב-`job-matching/references/scoring-prompt.md`.

## עלויות
JobSpy, ה-APIs של החברות ולוחות ה-remote — חינם. העלות היחידה היא קריאות ה-LLM: עד `llm_top_n` (ברירת מחדל 60) קריאות בריצה. עם `provider: none` הכול רץ חינם עם ניקוד היוריסטי.
