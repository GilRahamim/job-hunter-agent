# מדריך למשתמש: Job Hunter

הסוכן מחפש משרות בישראל ומשרות מרחוק שפתוחות לישראל, מדרג כל משרה לפי קורות החיים שלכם ומציג הכול בדשבורד, שבו גם עוקבים אחרי ההגשות.

## התקנה (פעם אחת)

1. מתקינים Python בגרסה 3.11 ומעלה.
2. בתיקיית הפרויקט מריצים:
   ```powershell
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. לא חובה: מודל שפה לדירוג מדויק יותר. מעתיקים את `.env.example` ל-`.env` ומוסיפים מפתח API. בלי מפתח הכול עובד עם ציון לפי מילות מפתח, בחינם.

## שימוש יומיומי

```powershell
streamlit run dashboard.py
```

1. בלשונית **פרופיל** מעלים קורות חיים (PDF, DOCX או TXT; קובץ PDF צריך להיות טקסטואלי ולא סרוק).
2. לוחצים **"בואו נמצא את המשרה הבאה"**. ריצה מלאה לוקחת כמה דקות, ואפשר לעצור אותה באמצע בלי לאבד את מה שנמצא.
3. בטבלת המשרות משנים סטטוס ומסמנים "נשלחו קו״ח". הסטטוסים לא נמחקים בריצות הבאות.

הדירוג לומד מהבחירות שלכם: משרות שסימנתם "מעניין" או "הוגשה מועמדות", ומשרות שסימנתם "לא רלוונטי", מוצגות למודל השפה כרמז בדירוג הבא.

## אדם נוסף באותו מחשב

בלשונית **פרופיל** ← **"הוספת אדם נוסף"**: כותבים שם, מעלים קורות חיים ואפשר גם לכתוב תפקידים לחיפוש. בראש הסרגל הצדדי בוחרים מי מחפש/ת.

- לכל אדם יש משרות, סטטוסים והגדרות משלו, בתיקייה `users/<מזהה>/`.
- התפקידים לחיפוש, סינון התחום ומגבלת שנות הניסיון נגזרים מקורות החיים. זה עובד גם למי שלא מחפש/ת משרות פיתוח. בלי מודל שפה צריך לכתוב את התפקידים בטופס.
- כדי לשנות הגדרה רק לאדם הזה, עורכים את `users/<מזהה>/config.yaml`. מה שלא כתוב שם נלקח מ-`config.yaml` הראשי.
- "הסוכן החכם" (המודל בוחר חיפושים) זמין רק למשתמש הראשי.

## הכנת מועמדות עם Claude, במנוי ולא דרך ה-API

בכרטיס המשרה פותחים את **"הכנת מועמדות עם Claude"** ולוחצים **"הכנת תיק למשרה"**. התיק כולל את המשרה, את קורות החיים ואת ניתוח ההתאמה.

- **עם Claude Code** (מותקן ומחובר עם חשבון Claude): הכפתור "פתיחה ב-Claude Code" פותח חלון חדש. Claude כותב קורות חיים מותאמים למשרה, מכתב מקדים, הכנה לראיון וקובץ `changes.md` עם השינויים והפערים, ומוסיף גם עותק Word של קורות החיים. הקבצים מופיעים בכרטיס המשרה להורדה.
- **בלי Claude Code**: "הורדת התיק ל-claude.ai", ומצרפים את הקובץ לשיחה חדשה ב-claude.ai או באפליקציה.
- מתוך Claude Code אפשר גם לכתוב `/apply <מזהה משרה>`. את המזהים מציג `python -m jobhunter.handoff --list`.

השימוש נספר במנוי Claude שלכם (Pro או Max) ולא בחשבון ה-API: הכפתור מסיר את מפתח ה-API מהסביבה של Claude Code, כי כשהמפתח נמצא בסביבה Claude Code מציע להשתמש בו במקום במנוי. התקנה והתחברות: https://code.claude.com/docs/en/setup.

הכלל החשוב: Claude לא מוסיף שום דבר שלא כתוב בקורות החיים. כדאי לקרוא את `changes.md` לפני השליחה.

## בעיות נפוצות

- **"another run is in progress"**: ריצה אחרת עדיין פעילה. אם היא תקועה, מוחקים את `data/run.lock` (אצל אדם נוסף: `users/<מזהה>/data/run.lock`).
- **LinkedIn מחזיר 429**: LinkedIn מגביל בקשות מהירות. הריצה ממשיכה עם שאר המקורות.
- **הציון "ראשוני" בלבד**: אין מודל שפה זמין, או שנגמר הקרדיט בחשבון ה-API. הסיבה מופיעה בסרגל הצדדי.
- **הפרופיל נראה שגוי**: מתקנים בלי לערוך את קורות החיים, ב-`config.yaml` תחת `profile.overrides`.
